## 实践课骨架（L09 / L19 / L39 / L48 / L62 / L68）

与理论课的差异：

- frontmatter 增加 `type: practice`；
- 「论文里的这段话」替换为「本次实践你要亲眼看到什么」（3–5 条可观察结论）；
- 正文结构改为：**〇、环境准备**（明确最低硬件：无 GPU 的 CPU/Mac 路径必须提供）→ **一、逐步任务**（每步：做什么 → 预期看到什么 → 为什么）→ **二、观察与解释**（把实验现象接回理论课）→ **三、挑战题**（可选进阶）；
- 代码块必须**完整可运行**（单文件优先，标注依赖版本），关键行加中文注释；
- 结尾保留「术语卡片 / 自测 / 延伸阅读」。

## 写作规范摘要（完整版见 [[AGENTS]]）

- 语言：中文正文，英文术语；语气像**师兄带你读论文**——直白、多打比方，但不牺牲准确性。
- 篇幅：正文 3000–6000 字（实践课代码为主，不受此限）。
- 图：Mermaid 优先，其次 ASCII/表格；**禁止引用不存在的图片文件**。
- 公式：行内 `$...$`，独立 `$$...$$`。
- 数字：一律用 [[03 约定与符号]] 的口径。
- 链接：wikilink 文件名必须与 [[00 课程总览]] 课程表完全一致（未写的课也可以链接，允许暂时是未解析链接）。
