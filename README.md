# 分布式 AI 系统基础 · Foundations of Distributed AI Systems

> **main 分支：70 / 70 课正文已完成** · 最新正式版本：`v0.1.0`（L01–L09）

面向「分布式训练 / 分布式推理的网络与系统优化」（MLSys × 计算机网络）方向入门研究生的 Obsidian 课程。目标是：**扫清读 AI Infra 顶会论文的术语与背景障碍**。

main 分支已完成 M0–M9 全部课程正文：内容从 AI 系统全景、深度学习基础和 Transformer/大模型出发，依次进入 GPU 与加速器、数据中心网络、集合通信、分布式训练、训练工程与可靠性、推理系统，最后落到跨集群、边云协同、生存性与仿真评测等研究专题。`v0.1.0` 是首个冻结版本；希望阅读完整课程时请使用 main 分支。

## 开始学习

1. 克隆或下载本仓库，在 Obsidian 中选择“打开文件夹作为 vault”。阅读课程不要求社区插件。
2. 从 [00 课程总览](00%20课程总览.md) 了解学习路线，再按顺序阅读 [L01 全景图](M0%20全景与方法/L01%20全景图.md) 到 [L69 研究地图与论文清单](M9%20前沿专题/L69%20研究地图与论文清单.md)；[L70 选修-多模态与新负载](M9%20前沿专题/L70%20选修-多模态与新负载.md) 为选修课。
3. 读论文时用 [02 术语总表](02%20术语总表.md) 查英文术语，用 [03 约定与符号](03%20约定与符号.md) 核对数字和单位。
4. 六节实践课 [L09](M1%20深度学习基础/L09%20实践-训练第一个模型.md)、[L19](M2%20Transformer与大模型/L19%20实践-解剖迷你GPT.md)、[L39](M5%20集合通信/L39%20实践-动手集合通信.md)、[L48](M6%20分布式训练并行/L48%20实践-并行策略推演.md)、[L62](M8%20推理系统/L62%20实践-跑起来一个推理服务.md)、[L68](M9%20前沿专题/L68%20实践-仿真上手.md) 均提供无 GPU 路径，可在 CPU 或 Apple Silicon 上完成；依赖、运行命令与预期现象写在各课的“环境准备”中。

`课程看板.base` 是可选的 Obsidian Bases 视图；即使不打开它，课程正文和进度看板也能正常使用。

## 贡献与 AI 协作

课程架构与完整课文由维护者统一维护。欢迎直接提交对**已完成课程**的事实勘误、来源补充、术语一致性修复、局部解释、图示或链接优化；不接受新增/补完未发布课程、课程结构调整或整篇 AI 生成内容。

AI 可以辅助小范围修订，但 PR 必须披露 AI 使用情况、人工核验情况和可核验来源。完整规则见 [CONTRIBUTING.md](CONTRIBUTING.md)，维护者的新课实现手册见 [AGENTS.md](AGENTS.md)。
