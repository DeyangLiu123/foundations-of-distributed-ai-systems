# M1 深度学习基础 · 设计稿

> 模块目标：给完全没学过 AI 的读者补齐「看懂训练系统论文所需的最小深度学习」。取舍标准：**系统论文里会出现的概念才讲**（如 optimizer states、activation），纯算法议题（正则化技巧、初始化理论）一律从简。全模块贯穿一个主角例子：一个小型 MLP 分类器。

## L03 机器学习速成

- **文件**：`M1 深度学习基础/L03 机器学习速成.md`
- **定位**：第一性原理：机器学习 = 用数据拟合函数。建立「数据/模型/损失/优化」四件套心智模型。
- **前置**：[[L01 全景图]]
- **核心问题**：① 「学习」在数学上到底是什么？② 为什么要分训练集和测试集？③ loss 是什么，为什么所有训练日志都在盯着它？
- **内容要点**：
  1. 从「写规则」到「学规则」：垃圾邮件识别的规则法 vs 学习法，引出「模型 = 带参数的函数 $f_\theta$」。
  2. 监督学习四件套：**dataset**（样本 = 输入 + 标签）、**model**、**loss function**（衡量预测与标签差距；先用 MSE 直觉，交叉熵留到 L05）、**optimization**（调 $\theta$ 使 loss 变小——只给「下山」直觉，机制留 L06）。
  3. 泛化：**train/validation/test split**、**overfitting/underfitting**（配经典 U 形曲线）、为什么「背答案」不算学会；**epoch** 在这里首次出现。
  4. 任务类型速览：classification / regression / 生成式（generative，预告 LLM 是「分类下一个词」）；supervised / self-supervised（预告预训练属于后者）/ reinforcement learning（一句话，指向 L15）。
  5. 与系统的接口：数据集大小（MNIST 60K 样本 → LLM 15T token）决定了 I/O 与存储问题；「训练 = 对数据集反复扫描」决定了数据管线（指向 L34）。
- **必收术语**：machine learning、supervised learning、self-supervised learning、dataset、sample、label、feature、model、parameter/weight、loss function、objective、training/validation/test set、overfitting、underfitting、generalization、epoch、classification、regression、inference（ML 语义）。
- **定量环节**：算数据集规模：MNIST（6万张 28×28 灰度图 ≈ 47 MB）vs ImageNet（~1.3M 张图 ≈ 150 GB）vs LLM 预训练集（15T token 的 token-id 数组 ≈ 32–60 TB，取决于位宽口径——L14 细算）——三个数量级台阶，让「数据供给是系统问题」有体感。
- **图示**：① 四件套关系图（数据→模型→预测→loss→更新参数的闭环）；② overfitting U 形曲线。
- **延伸阅读**：《动手学深度学习》（d2l.ai，中文，第 1–3 章）——本模块的标准配套教材；3Blue1Brown《What is a neural network?》视频（B 站有官方中字）。
- **误区**：「模型 = 代码」——模型是参数（一堆浮点数），代码只是执行它的框架；「训练准确率高就是好」——看的是没见过的数据。

## L04 神经网络与前向传播

- **文件**：`M1 深度学习基础/L04 神经网络与前向传播.md`
- **定位**：拆开 $f_\theta$：神经网络就是「矩阵乘法 + 非线性」的堆叠。本课同时是**张量形状训练课**——追形状是读一切模型代码/论文的基本功。
- **前置**：[[L03 机器学习速成]]
- **核心问题**：① 一个神经网络里面到底是什么运算？② 输入一张图/一句话，形状怎么一层层变化？③ 为什么说「深度学习 = GEMM」？
- **内容要点**：
  1. 单个神经元 = 加权和 + **activation function**；为什么需要非线性（否则塌缩成一个线性层）。激活函数只讲 ReLU（+ 提名 GELU/SwiGLU 在 LLM 里等着你，L12 见）。
  2. 全连接层 = 矩阵乘：$y = Wx + b$；堆叠成 **MLP**。引入 **hidden layer / hidden size / depth / width**。
  3. **张量（tensor）**与形状：标量/向量/矩阵/高维张量；**batch 维**——为什么一次算一批（效率，预告 GPU 吞吐逻辑）；形状记号 `[B, D_in] × [D_in, D_out] → [B, D_out]`，全课程沿用。
  4. 输出层：**logits** → **softmax** → 概率分布；一句话给 argmax vs sampling（细节 L13）。
  5. **前向传播（forward pass）**完整走一遍主角 MLP（784→256→128→10），逐层标形状与参数量。
  6. 与系统的接口：**GEMM**（General Matrix Multiply）是深度学习 90% 的计算；参数量 × dtype 字节数 = 模型体积（第一次显存估算）。
- **必收术语**：neuron、activation function、ReLU、GELU（提名）、fully-connected/linear layer、MLP、hidden layer、hidden size、depth/width、tensor、shape、batch dimension、logits、softmax、probability distribution、forward pass、GEMM、FLOPs（首次正式定义：一次乘加 = 2 FLOPs）。
- **定量环节**：主角 MLP 参数量手算：784×256+256 + 256×128+128 + 128×10+10 = 235,146；FP32 体积 ≈ 0.94 MB。再算一次 forward 的 FLOPs：≈ 2×(784×256+256×128+128×10)×B。建立「参数量↔体积↔计算量」三连算。
- **图示**：① MLP 结构图（标形状）；② 「一层 = 一次 GEMM」示意（矩阵块图）。
- **延伸阅读**：d2l.ai 第 4 章（多层感知机）；3Blue1Brown 神经网络系列第 1 集。
- **误区**：「神经网络很神秘」——前向传播只是初中就会的乘加运算堆出来的；「参数量 = 计算量」——两者相关但不同（L16 会给精确关系 2N）。

## L05 反向传播与梯度

- **文件**：`M1 深度学习基础/L05 反向传播与梯度.md`
- **定位**：训练的数学心脏。目标不是让读者会手推，而是理解**梯度是什么、backward 为什么存在、为什么必须保存 activation**——最后一点是后面所有显存分析（L40）的地基。
- **前置**：[[L04 神经网络与前向传播]]
- **核心问题**：① 「往 loss 下降的方向调参数」——方向怎么算出来的？② backward pass 里到底在算什么？③ 为什么训练比推理贵、比推理占显存？
- **内容要点**：
  1. **gradient** 的直觉：多维空间的「坡度」，指向 loss 上升最快方向，取反即下降方向；一维/二维可视化。
  2. **交叉熵损失**：分类为什么不用 MSE；$-\log p_{正确}$ 的直觉（对正确答案的置信度罚款）——LLM 的 loss 就是它（预告 L14 的 loss 曲线）。
  3. **链式法则**与**计算图（computational graph）**：用一个三节点小例子完整手推一遍；然后宣布「框架用 **autograd** 自动做这件事」。
  4. **backward pass** 的两笔账：对权重的梯度（用来更新）+ 对输入的梯度（用来继续往前传）；每层都要用到**前向时的中间结果（activation）** → **所以前向必须把 activation 存下来** → 训练显存 = 参数 + 梯度 + activation（+优化器状态，下课补全）。
  5. 计算量结论（记住即可，L16 推导）：backward ≈ 2× forward FLOPs；训练每 token ≈ 6N，推理 ≈ 2N。
  6. 梯度的病：**vanishing/exploding gradient**（一句话 + 残差连接是解药之一，指向 L12）；**NaN/Inf**（预告混合精度 L49 的 loss scaling）。
- **必收术语**：gradient、cross-entropy loss、chain rule、computational graph、autograd/automatic differentiation、backward pass、activation（中间激活值——注意与 activation function 区分！）、gradient with respect to weights/inputs、vanishing/exploding gradient、NaN。
- **定量环节**：主角 MLP 上算一笔「训练 vs 推理」显存对比：推理只需参数 0.94 MB + 当前层 activation；训练需参数 + 全部 activation（batch=256 时逐层算）+ 梯度 ≈ 3× 以上。得出「训练贵在存」的结论雏形。
- **图示**：① 计算图 + 前向/反向箭头（Mermaid）；② 「forward 存 activation，backward 消费 activation」的时间线图（这张图 L40/L50 会反复引用）。
- **延伸阅读**：3Blue1Brown《Backpropagation, intuitively》；Karpathy《The spelled-out intro to neural networks and backpropagation: building micrograd》（YouTube，本模块最佳补充，实践课 L09 会用到它的思路）；d2l.ai 第 5 章。
- **误区**：**activation function ≠ activation**（前者是函数，后者是要占显存的中间张量——论文里 activation memory 指后者）；「backward 是玄学」——它只是链式法则的机械执行。

## L06 优化器

- **文件**：`M1 深度学习基础/L06 优化器.md`
- **定位**：从「有了梯度」到「更新参数」。核心系统结论：**Adam 系优化器要为每个参数额外存 2 个状态量**——这是 ZeRO（L42）存在的全部理由。
- **前置**：[[L05 反向传播与梯度]]
- **核心问题**：① 有了梯度为什么还不够，还要「优化器」？② optimizer states 是什么、有多大？③ 论文里的 learning rate schedule / warmup 是在干嘛？
- **内容要点**：
  1. **GD → SGD → mini-batch SGD**：为什么用小批量（全量算不动 + 噪声有益）；**batch size** 与梯度噪声的关系（大 batch 梯度更准但每步更贵）。
  2. **learning rate**：太大发散、太小龟速；**LR schedule**：warmup（训练初期小步走稳，大模型必备）+ cosine decay（LLM 标配）；读训练日志里的 lr 曲线。
  3. **momentum**：滚雪球平滑震荡；**Adam/AdamW**：为每个参数维护一阶矩 m、二阶矩 v（自适应步长直觉即可，不推公式）；weight decay 一句话。
  4. **系统重点——optimizer states**：Adam 的 m、v 各一份 FP32 → 每参数 8 B；加上 FP32 master weights（预告 L49）→ 混合精度训练 16 B/参数记账法首次完整亮相（引用 [[03 约定与符号]]）。
  5. **gradient clipping**（防梯度爆炸，训练日志常客 grad_norm）；loss 曲线病理学入门：发散、loss spike（深入 L14/L49）。
  6. 大 batch 与并行的接口：全局 batch size 是并行度的上限之一（预告 L41 的 linear scaling rule 与 L47 的 batch 约束）。
- **必收术语**：optimizer、gradient descent、SGD、mini-batch、batch size、learning rate、learning rate schedule、warmup、cosine decay、momentum、Adam、AdamW、weight decay、optimizer states、first/second moment、gradient clipping、grad norm、convergence、loss curve、loss spike。
- **定量环节**：7B 模型的优化器状态：m + v = 7×10⁹ × 8 B = 56 GB；加 FP32 master weights 28 GB → 光「优化器相关」就 84 GB > 一张 H100 的 80 GB。**这一个数字就是 M6 整个模块的动机**，务必算清并强调。
- **图示**：① 不同 LR 的下山轨迹示意；② warmup + cosine 的 lr 曲线；③ 「一个参数在训练中随身携带的东西」示意图（param/grad/m/v/master，标字节数）。
- **延伸阅读**：d2l.ai 第 12 章（优化算法）；《Adam: A Method for Stochastic Optimization》（ICLR 2015，只读第 2 节算法框）。
- **误区**：「优化器状态是小开销」——它是参数的 3 倍显存；「lr 越大训练越快」——warmup 的存在恰恰说明不是。

## L07 训练循环解剖

- **文件**：`M1 深度学习基础/L07 训练循环解剖.md`
- **定位**：把 L03–L06 组装成读者以后天天要看的东西：**一个标准 PyTorch 训练循环**。同时讲清 batch 语义体系（micro/global/accumulation）——分布式论文里最容易犯迷糊的一组词。
- **前置**：[[L06 优化器]]
- **核心问题**：① 一段训练代码从上到下每行在干嘛？② step、iteration、epoch、token 数——论文报训练进度的四种口径怎么换算？③ gradient accumulation 是什么，为什么大模型离不开它？
- **内容要点**：
  1. 20 行标准 PyTorch 训练循环逐行讲解：dataloader → forward → loss → `loss.backward()` → `optimizer.step()` → `zero_grad()`；每行标注「对应 L 几的概念」。
  2. **DataLoader**：shuffle 为什么必要、num_workers 与预取（这是很多训练慢的真凶，预告 L52 的 dataloader stall）。
  3. 进度口径：**step/iteration**（一次参数更新）、**epoch**（过一遍数据）、LLM 时代改用 **token 数**（15T tokens ÷ (GBS×S) = 总 step 数，给公式）。
  4. **gradient accumulation**：显存装不下大 batch → 多个 micro-batch 累积梯度再更新；`GBS = micro_bs × grad_accum × DP`（此时 DP=1，公式完整版 L47 回收）。
  5. **checkpoint 基础**：state_dict 里有什么（参数 + 优化器状态！）、save/load/resume；7B 模型 ckpt ≈ 参数 14 GB + 优化器 84 GB 量级 → 预告 L34/L53 的 checkpoint 工程。
  6. 随机性与可复现：random seed、cudnn deterministic 一句话。
- **必收术语**：training loop、DataLoader、shuffle、prefetch、step/iteration、epoch、global batch size（GBS）、micro-batch、gradient accumulation、state_dict、checkpoint、resume、random seed、logging（loss/lr/grad_norm 三件套）、wandb/TensorBoard（提名）。
- **定量环节**：Llama-3 风格换算题：D=15T token、S=8192、GBS=2048（序列数）→ 每 step 消耗 2048×8192 ≈ 1.68×10⁷ token → 总 step ≈ 9×10⁵。让读者学会从论文表格反推训练日程。
- **图示**：① 训练循环流程图（Mermaid，节点标注概念出处课号）；② micro-batch/accumulation/GBS 关系图（方块堆叠）。
- **延伸阅读**：PyTorch 官方教程《Training a Classifier》；d2l.ai 对应章节。
- **误区**：「batch size」单指一个数——分布式语境下不注明 micro/global 就是歧义；「epoch 是通用单位」——LLM 预训练常常不足 1 epoch。

## L08 CNN与RNN简史

- **文件**：`M1 深度学习基础/L08 CNN与RNN简史.md`
- **定位**：轻量历史课，两个目的：① 读懂老一代系统论文（PipeDream、ByteScheduler 等）里的 ResNet/LSTM/BERT 基准；② 讲清「RNN 为什么输给 Transformer」——这是理解 Transformer 系统友好性的最佳切入点。可快读。
- **前置**：[[L04 神经网络与前向传播]]
- **核心问题**：① CNN/RNN 各自的归纳偏置是什么？② 为什么 RNN 训练无法并行？③ 老论文的 benchmark 模型今天还要认识吗（要）？
- **内容要点**：
  1. **CNN**：卷积 = 滑动窗口的参数共享；pooling；**ResNet** 与 **residual connection**（这个概念活到了 Transformer 里，L12 回收）；ImageNet 时刻（2012 AlexNet）一段话。
  2. **RNN/LSTM**：处理序列的思路（隐状态循环）；**致命伤：时间步之间串行依赖 → 无法在序列维并行 → GPU 吃不饱**；长程依赖遗忘问题。
  3. **seq2seq 与 encoder-decoder**：机器翻译管线；attention 作为「外挂」首次登场（为 L11 铺垫：Transformer = 只留 attention）。
  4. 硬件彩票（hardware lottery）论点：Transformer 赢在「全是大 GEMM、天然并行」，与 GPU 互相成就——系统视角看模型演化的钥匙。
  5. 老基准速查表：ResNet-50（25M 参数）、BERT-base/large（110M/340M）、GPT-2（1.5B）——读 2018–2021 系统论文时的「时代坐标」。
- **必收术语**：CNN、convolution、kernel/filter（卷积语义——与 GPU kernel 区分！）、pooling、ResNet、residual connection/skip connection、ImageNet、RNN、LSTM、hidden state、sequential dependency、seq2seq、encoder-decoder、BERT、masked language model（一句话）、hardware lottery。
- **定量环节**：并行度对比：RNN 处理 S=2048 的序列需 2048 步串行；Transformer 一次矩阵乘并行处理全部 2048 个位置——用「关键路径长度」语言表述（S 步 vs 常数步）。
- **图示**：① RNN 展开图（标出串行依赖链）vs Transformer 并行处理示意；② 模型演化时间线（1998 LeNet → 2012 AlexNet → 2015 ResNet → 2017 Transformer → 2018 BERT/GPT）。
- **延伸阅读**：《Deep Residual Learning for Image Recognition》（CVPR 2016，只看图 2 的残差块）；Sara Hooker《The Hardware Lottery》（CACM 2021）。
- **误区**：「CNN/RNN 过时了不用学」——系统论文的 baseline 与 trace 里到处都是；kernel 一词三义（卷积核/GPU kernel/OS kernel），本课起要求读者按上下文区分。

## L09 实践-训练第一个模型

- **文件**：`M1 深度学习基础/L09 实践-训练第一个模型.md`
- **定位**：【实践课】把 M1 全部概念落到一份 ~80 行、CPU/Mac 可跑的 PyTorch 脚本上。原则：**每个现象都要能指认出它对应哪个概念**。
- **前置**：[[L07 训练循环解剖]]
- **实践目标（读者要亲眼看到）**：① loss 从 ~2.3 降到 <0.1 的完整曲线；② 改大 learning rate 看 loss 发散；③ 改 batch size 观察每步耗时与收敛的变化；④ 打印 model.parameters() 数出参数量与手算一致；⑤ 保存/加载 checkpoint 并续训。
- **内容要点**：
  1. 环境准备：Python + PyTorch（CPU 版即可，给 pip 命令与版本）；数据用 MNIST（torchvision 自动下载）或 FashionMNIST。
  2. 完整脚本：主角 MLP（784→256→128→10）+ AdamW + 交叉熵，逐块注释对应 L03–L07。
  3. 五个实验任务（对应上面五个目标），每个给「预期现象 + 解释 + 指回理论课」。
  4. 观察显存/内存：`psutil` 或任务管理器粗看训练 vs 推理的内存差（呼应 L05）。
  5. 挑战题：把优化器换成 SGD 对比收敛；用 `torchinfo.summary` 看逐层形状；故意把 lr 设成 10 看 NaN。
- **必收术语**：（复习课，不引入新术语；术语卡片改为「本课验证过的 10 个概念」清单）
- **延伸阅读**：Karpathy micrograd 视频（想真正搞懂 autograd 的人）；PyTorch 官方 Quickstart。
